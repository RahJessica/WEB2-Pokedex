# WEB2-Pokedex
# Pokedex react app 
This project is a simple web application for consulting Pokémon information via the PokéAPI public API. We will only use React, FastAPI and CSS / Tailwindcss

## Functionalities :
- Search for a pokémon by name or number
- Display pokémon details (image, name, statistics)

## Technologies used :
- React + vite
- FastAPI
- CSS and Tailwindcss
